# 코디세이 2주차 · 사자성어 퀴즈

사자성어의 뜻을 읽고 네 개의 보기 중 알맞은 말을 고르는 Python 터미널 게임입니다. 기본 문제 5개로 시작하며, 사용자가 직접 문제를 추가할 수 있습니다. 한 판을 끝내면 맞힌 문제 수를 기록하고, 다음 실행에서 이전 점수를 다시 볼 수 있습니다.

## 주제 선정 이유

사자성어는 뜻 하나를 질문으로, 짧은 단어 네 개를 보기로 구성하기 쉽습니다. 예를 들어 “상대방의 처지에서 생각해 본다”라는 뜻을 보고 ‘역지사지’를 고르는 방식입니다. 같은 형식으로 새 문제를 만들면서 Python의 입력 검증, 객체를 이용한 채점, JSON 파일 저장을 한 프로그램에서 연습할 수 있어 이 주제를 선택했습니다.

## 실행 방법

실습 환경은 Windows, Python 3.12.6, VS Code, MSYS2 UCRT64 Bash입니다. Python 표준 라이브러리만 사용합니다. 처음 내려받아 실행할 때는 다음 명령을 입력합니다.

```bash
git clone https://github.com/skypark-kr/week2.git
cd week2
python main.py
```

이미 저장소를 내려받았다면 `main.py`가 있는 폴더에서 `python main.py`를 실행합니다. 메뉴 번호를 입력하고 Enter를 누르면 해당 기능이 시작됩니다.

## 메뉴와 기능

| 번호 | 메뉴 | 동작 |
| --- | --- | --- |
| 1 | 퀴즈 시작 | 등록된 문제를 순서대로 풉니다. 매 문제의 정답 여부를 바로 알려 주고, 오답이면 정답 번호를 표시합니다. 끝까지 풀면 한 판의 점수를 저장합니다. |
| 2 | 퀴즈 추가 | 질문, 보기 4개, 정답 번호(1~4)를 입력하면 새 문제를 목록 끝에 추가하고 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 문제 수와 각 질문을 번호순으로 보여 줍니다. |
| 4 | 점수 확인 | 완료한 게임의 점수를 회차순으로 보여 줍니다. 기록이 없으면 '점수가 없습니다.'를 표시합니다. |
| 5 | 종료 | 게임을 마치고 터미널로 돌아갑니다. |

메뉴나 정답 번호에 빈 값, 문자 또는 범위를 벗어난 숫자를 입력하면 같은 항목을 다시 묻습니다. 문제를 추가할 때도 빈 질문이나 빈 보기는 다시 입력받습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `main.py` | 프로그램 시작점입니다. 메뉴와 숫자 입력을 처리하고, `QuizGame` 클래스가 출제·문제 추가·목록 조회·점수 조회를 담당합니다. |
| `quiz.py` | 문제 한 개를 나타내는 `Quiz` 클래스입니다. `show()`는 질문과 보기를 출력하고 `is_correct()`는 선택한 번호를 채점합니다. |
| `quiz_data.py` | 첫 실행에 사용할 기본 사자성어 문제 5개를 생성합니다. |
| `storage.py` | 퀴즈와 점수를 JSON으로 저장하고, 저장한 문제를 다시 `Quiz` 객체로 불러옵니다. |
| `state.json` | 실행 중 생성되는 로컬 데이터 파일입니다. `.gitignore`에 등록되어 있습니다. |

## 저장 형식

첫 실행 시 `storage.py`와 같은 폴더에 `state.json`이 생성됩니다. 다음은 문제 한 개와 점수 한 건으로 구성한 형식 예시입니다.

```json
{
  "quizzes": [
    {
      "question": "지난 잘못을 고쳐 바른길로 돌아간다",
      "choices": ["이심전심", "개과천선", "유비무환", "동문서답"],
      "answers": 2
    }
  ],
  "scores": [
    {"correct": 1, "total": 1}
  ]
}
```

`answers`는 **1부터 세는 보기 번호**입니다. 위 예시의 정답은 두 번째 보기인 ‘개과천선’입니다. `scores`에는 한 판을 마칠 때마다 정답 수(`correct`)와 그 판의 전체 문제 수(`total`)를 함께 기록합니다. 이후 문제를 추가해도 지난 회차의 전체 문제 수는 당시 값으로 표시됩니다.

기본 5문제에 “좋은 일에 또 좋은 일이 더해진다”를 추가하고 세 번째 보기 ‘금상첨화’를 정답으로 지정했습니다. 게임을 종료한 뒤 다시 실행해 다음 결과를 확인했습니다.

| --- | --- |
| 추가한 문제 불러오기 | 총 6문제가 표시되고, 마지막 문제의 3번 보기가 정답으로 판정됐습니다. |

| 재실행 후 점수 조회 | 메뉴 4에서 `1회차: 6/6 문제 맞춤`이 표시됐습니다. |
